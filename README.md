# UI/UX Design: SCHEDULE (Desk Fitness App)
**Decode Labs Internship | UI/UX Design Track - Project 1: The Empathy Map**

## 📌 Project Overview
**SCHEDULE** is an ultra-accessible desk fitness companion designed for busy office professionals who struggle to find time for exercise. Before designing a single pixel, we focus on mapping user psychology and workflow barriers to create an interface that seamlessly integrates quick, healthy movement breaks into a demanding desk-bound workday.

## 👥 Target User Persona
* **Name:** Sarah
* **Age:** 32
* **Post / Role:** Software Engineer
* **Work Time:** 9–10 Hours/day (highly sedentary desk environment)

---

## 🧠 The 4-Quadrant Empathy Map
Mapped from real user observations to capture both the internal feelings and external obstacles of desk-bound professionals.

| Quadrant | User Experience Observations |
| :--- | :--- |
| **🗣️ SAYS** | • "I'll absolutely start stretching and working out this coming Monday." <br> • "If this meeting doesn't wrap up in five minutes, I'm going to start responding in code." |
| **💭 THINKS** | • "I am so tired, I want to lie down." <br> • "My life outside of this building is completely nonexistent right now." |
| **🏃 DOES** | • Sits for 10 hours a day with no walks or breaks. <br> • Drinks strong coffee to avoid afternoon energy slumps. |
| **❤️ FEELS** | • Overwhelmed by complex fitness apps demanding a one-hour gym commitment. <br> • Guilty when looking at a tracker for daily steps. |

---

## ⚠️ Pains & Gains Analysis

### ❌ User Pains
* **Physical Discomfort:** Severe back pain resulting from sitting for prolonged, uninterrupted hours.
* **Time Poverty:** Back-to-back calendar meetings leave zero open schedules for standard long workouts.

### 💡 User Gains
* **Ergonomic Support:** Utilizing ergonomic workspace elements to provide direct back relief and physical comfort.
* **Micro-Habit Success:** Accessing quick, 5-minute standup exercises that prevent strain without interrupting work schedules.
